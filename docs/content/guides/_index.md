Each guide is built around a job rather than a command. They assume you have run
the [quick start](/getting-started/quick-start/).

- [Collect data](/guides/collecting-data/): turn commands into datasets with
  jq, CSV, and a database tee.
- [Resource URIs](/guides/resource-uris/): use twitch as a `database/sql`-style
  driver so a host can address Twitch as `twitch://` URIs.
- [Add a command](/guides/adding-a-command/): model a Twitch record and turn
  it into a command, a route, and a tool at once.
